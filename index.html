Power Automate Workflow

Automated Incident Report System

A multi-step automation that converts digital form submissions into standardized, professionally formatted incident reports.

Problem

Manual report formatting created an inconsistent process.

Staff were manually formatting incident reports, which required additional administrative time and made it difficult to maintain a consistent report structure.

Solution

Built an automated document-generation workflow.

I created a workflow using Microsoft Forms, Excel, Office Scripts, Power Automate, HTML, and Outlook. The system collects the information, processes the data, generates a formatted report, and emails it to the appropriate recipients.

Results

  • Streamlined reporting: Eliminated manual formatting by automatically generating and distributing standardized incident reports, creating a faster and more consistent process across the organization.
  • Improved communication: Ensured HR, Risk Management, and organizational leaders received timely, consistent incident information, improving communication and supporting faster follow-up when incidents occurred.
  • Enabled data-driven insights: Centralized incident data across branches, allowing leadership to identify common incident types, branches with the highest number of incidents, and organization-wide trends to help guide prevention efforts and operational decisions.
